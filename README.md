# WeaponsOfMassDestruction
WMDs Mod for Neforge 26.1.2
To play this mod you have to go to https://neoforged.net/ and select 26.1.2 then click "click here to downlaod the installer" click on the .jar file and press "ok" after that select "install client" and click proceed
after that you press WIN+R and enter "%appdata%\.minecraft" or the location of your minecraft. Then create a mods folder (if not already there) and put my file in there. Note that the folder has to be called "mods". 
Also make sure no other mod incompatible with neoforge 26.1.2 is in the mods folder
